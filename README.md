# CallFlow Bench

An IVR testing tool for Amazon Connect and beyond.

## What is this?

CallFlow Bench is a lightweight Windows tool for testing interactive voice
response (IVR) call flows. It places a real phone call, then automatically
walks through a sequence of touch-tone and spoken inputs — while you listen
to (and optionally record) exactly what happens on the other end.

No more manually dialing in, waiting through prompts, and pressing buttons by
hand every time you need to verify a flow still works. Build a script once,
save it, and re-run it whenever you need to — on its own, or as part of a
batch of several scripts run back-to-back.

## Features

- **Script Builder** — sequence touch-tone input, spoken text, and hang-up
  steps, with per-step timing control
- **Phone Book** — save and reuse the numbers you test against most
- **Batches** — group a few scripts together and run them one after another
- **Automatic recording** — every call is saved and played back
  automatically, no separate login or account needed
- **Zero setup** — a single portable `.exe`, no installer required
